# 2025-03-03 ESGF-1.5 Status

ESGF-1.5 status as of March 3, 2025.

**NOTE:** ESGF-1.5 will be used for CMIP6 and earlier activities. *The following does not apply to CMIP7 and subsequent activities.*

## What has changed?
* **Index Consolidation and Transition** - ESGF-1.5 consolidates and transitions three Solr indexes at LLNL, ORNL, and ANL into a single ESGF2-US wide Globus Search index operated by US-Globus.
* **Read-only Projects** - These projects transition to read-only metadata: CMIP3, CMIP5, CREATE-IP, E3SM-supplement, GeoMIP, LUCID, TAMIP
* **Retired Projects** - These project will no longer be indexed: NARR_Hydrology
* **Software Changes** - Only those necessary to support Index Consoliation and Transition

Projects that will **NOT CHANGE** and continue to be publishable in ESGF-1.5: CMIP6, CMIP6Plus, DRCDP, E3SM, input4MIPs, obs4MIPs

## Conceptual Overview and Design
* Design documents are available in the [esgf2-us/esgf-1.5-design](https://github.com/esgf2-us/esgf-1.5-design) GitHub repository.

## Status Updates

### Planning

ESGF-1.5 requirements, designs, issues / tasks with assignee(s), milestones, the overall timeline are now mostly in the the [esgf2-us/esgf-1.5-design](https://github.com/esgf2-us/esgf-1.5-design) GitHub repository.

The progress on issues / tasks is being tracked in GitHub through completion at the end of May 2025.

### Metadata Schema Changes

* The index_node metadata attribute will be set to "us-index", replacing references to Solr indexes.

### Metadata Catalog Changes

* There will be a single public ESGF2-US Globus Search index with all the metadata for US hosted datasets and files
** The index will have Type=Dataset entries transfered from the LLNL Solr
** The index will have Type=File entries from the three LLNL, ORNL, and ANL Solr indexes
** The index will have Type=File entries for all US based data nodes, including data notes not at LLNL, ORNL, and ANL
** The index will have one Type=File entry for each file replica on a data node
** The index will only contain metadata for the CMIP3, CMIP5, CMIP6, CREATE-IP, DRCDP, E3SM, E3SM-supplement, GeoMIP, input4MIPS2, LUCID, obs4MIPs, and TAMIP projects
* There will be project specific staging Globus Search indexes containing
** Type=Dataset entries for all datasets in a project
** Type=File entries for all files in a project
* Metadata in ESGF-1.0 for NARR_Hydrology, CMIP7, or other future projects will not be available once ESGF-1.0 is retired
* The three Solr catalogs in LLNL, ORNL, and ANL will be retired at the end of this project.

### Metadata Transfer

TBD staff will transfer metadata listed above under Metadata Catalog Changes from Solr to Globus Search indexes:

To ESGF2-US wide Globus Search index:
* Read-only metadata for CMIP3, CMIP5, CREATE-IP, E3SM-supplement, GeoMIP, LUCID, TAMIP will be loaded into the

To ESGF2-US project specific staging Globus Search indexes:
* Read-write metadata for CMIP6, CMIP6Plus, DRCDP, E3SM, input4MIPs, obs4MIPs

The initial transfer, any refreshes, and the final transfer will generate audit that can be inspected by the team and include:
* Date of transfer
* Source Solr index
* Which project or query parameters were used to retrieve metadata
* The target Globus index (staging of public)
* The number of metadata entries process
* The Globus Search ingest ID
* The Globus Search ingest response code

#### Metadata synchronization from staging to ESGF-US wide catalog:
* A configurable synchronizer will be developed between staging and the ESGF-US wide catalog
 
### Publishing Metadata

Publishing under ESGF-1.5 will involve:
* Using esg-publisher configured with a target staging Globus Search index publishing credential
* The esgf-1.5-metadata-synchronizer will aggregated staged metadata into the public ESGF2-US Globus Search index
** Only entries in the staged catalog that be updated (Dataset or File)
** Logged esgf-1.5-metadata-synchronizer activity will be logged or tracked for audit purposes
