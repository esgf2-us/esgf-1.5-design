# 2025-03-03 ESGF-1.5 Status

ESGF-1.5 status as of March 3, 2025.

**NOTE:** ESGF-1.5 will be used for CMIP6 and earlier activities. *The following does not apply to CMIP7 and subsequent activities.*

## What has changed?

The following design elements have been finalized, are ready to fully implement and to communicate to relevant stakeholders:

- **Index Consolidation and Transition:** ESGF-1.5 will consolidate and transitions three Solr indexes at LLNL, ORNL, and ANL into a single ESGF2-US wide public Globus Search index operated by US-Globus.
- **Staging Indexes:** ESGF-1.5 will use private staging Globus Search indexes for projects with read-write metadata to protect metadata from unauthorized or accidental alteration
- **Staging Synchronization:** Metadata published to Staging Indexes will be automatically synchronized to the ESGF2-US wide Globus Search index, and thus results in a delay between publishing to the staging index, and visibility in the ESGF2-US wide public search index.
- **Read-only Projects:** These projects will transition to read-only metadata: CMIP3, CMIP5, CREATE-IP, E3SM-supplement, GeoMIP, LUCID, TAMIP
- **Retired Projects:** These project will no longer be indexed: NARR_Hydrology
- **Software Changes:** Software changes necessary to access Globus Search directly, or through a new esgf_fastapi service
- **XML encoded metadata:** Metadata will no longer be available in XML format, thought many third party tools available to convert JSON to XML
- **Read-write Projects:** These project will continue to be publishable (read-write) in ESGF-1.5: CMIP6, CMIP6Plus, DRCDP, E3SM, input4MIPs, obs4MIPs
- **Non-US Metadata:** Search interfaces will no longer return metadata from Solr indexes outside the US
