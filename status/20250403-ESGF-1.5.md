# 2025-04-03 ESGF-1.5 Status

** DRAFT **

ESGF-1.5 status as of April 3, 2025.

**NOTE:** ESGF-1.5 will be used for CMIP6 and earlier activities. *The following does not apply to CMIP7 and subsequent activities.*

## What has changed?

The following implementation/development elements are complete, are ready for end-to-end pre-production testing, and may be communicated to relevant stakeholders:

- **Index Consolidation and Transition:** A new ESGF2-1.5 Public Index and several staging indexes have been defined is Globus Search and documented in [indexes.md](https://github.com/esgf2-us/esgf-1.5-design/indexes.md).
- **Initial Metadata Transfer:** The ESGF2-1.5 Public Index and the staging indexes were loaded with all metadata identified in scope for each from the LLNL, ORNL, and ANL Solr indexes.
- **Staging Synchronization:** The tool to synchronize metadata from the staging indexes to the public index is under developed. This will result in a delay between publishing to the staging index, and visibility in the ESGF2-US wide public search index.
- **Software Changes:** Software changes necessary to access Globus Search directly, or through a new esgf_fastapi service were completed.
- **End-to-end pre-production testing:** A preliminary end-to-end pre-production testing plan has been drafted in [testing.md](https://github.com/esgf2-us/esgf-1.5-design/testing.md)

## Implementation / Development
- Metadata transfer from Solr indexes to Globus Searchg indexes are tracked at [https://minxu74.github.io/metadata_docs/](https://minxu74.github.io/metadata_docs/).
- The status of individual software development or improvement changes should be documented in the GitHub repo for each tool. See [ESGF-1.5 Changes](../changes.md).
